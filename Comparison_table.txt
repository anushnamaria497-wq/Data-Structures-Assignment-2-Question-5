COMPARISON: Linear Search vs Binary Search (n = 8)

Criterion              | Linear Search                  | Binary Search
Pre-condition          | None                           | Data must be sorted
Time complexity        | O(n)                           | O(log n)
Comparisons observed   | Testing 6, Frontend 7, HR 2,   | Testing 4, Frontend 3, HR 2,
                       | Marketing (absent) 8           | Marketing (absent) 4
Extra cost             | None                           | Sorting once: O(n log n)
Space                  | O(1)                           | O(1)
Best when              | Small / unsorted / changing    | Large, mostly static, kept sorted
