COMPARISON: LINEAR SEARCH VS BINARY SEARCH
==========================================

| Criterion              | Linear Search | Binary Search |
|------------------------|---------------|---------------|
| Sorted data required   | No            | Yes           |
| Search method          | Sequential    | Divide and Conquer |
| Best case              | O(1)          | O(1)          |
| Average case           | O(n)          | O(log n)      |
| Worst case             | O(n)          | O(log n)      |
| Extra space            | O(1)          | O(1)          |


OBSERVED SEARCH COMPARISONS
===========================

| Department  | Linear Search | Binary Search |
|-------------|---------------|---------------|
| Development | 2             | 2             |
| HR          | 5             | 3             |
| Testing     | 7             | 3             |


TREE ANALYSIS
=============

Number of departments = 7
Number of tree nodes = 8
Tree height = 3 edges
Number of levels = 4

Level-order traversal:

CEO HR Finance IT Development Testing Frontend Backend


SUMMARY
=======

Linear Search can be used with unsorted data.

Binary Search requires sorted data and generally
requires fewer comparisons as the number of
departments increases.

For the given department list, Binary Search required
fewer comparisons for HR and Testing.
