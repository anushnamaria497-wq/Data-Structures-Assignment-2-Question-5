COMPLEXITY ANALYSIS  (n = number of departments)

Tree height: 3 (root CEO at level 0; Frontend and Backend at level 3). 8 nodes.
The tree is irregular: CEO has 3 children, IT and Development have 2, the rest are leaves.

Operation                    | Best   | Average | Worst  | Space
Tree construction            | O(1)/node | O(1)/node | O(1)/node | O(n)
Level-order traversal (BFS)  | O(n)   | O(n)    | O(n)   | O(n) queue
Linear Search                | O(1)   | O(n)    | O(n)   | O(1)
Binary Search (sorted array) | O(1)   | O(log n)| O(log n)| O(1)
Sorting for Binary Search    | -      | -       | O(n log n) (one-time; Bubble Sort used here is O(n^2))

Observed: Linear Search needed 2-8 comparisons; Binary Search needed 2-4
(theoretical maximum floor(log2 8) + 1 = 4). Absent key "Marketing" is the
worst case for both: 8 vs 4 comparisons.
