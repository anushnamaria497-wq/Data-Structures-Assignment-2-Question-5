COMPLEXITY ANALYSIS
===================

1. TREE STRUCTURE

Number of nodes = 8

Tree height = 3 edges

Number of levels = 4

Tree storage:
Time/Space = O(n)

Level-order traversal:
Time Complexity = O(n)

Auxiliary Space:
O(n), because a queue is used.


2. LINEAR SEARCH

Linear Search checks the elements one by one.

Best Case Time Complexity = O(1)

Worst Case Time Complexity = O(n)

Average Case Time Complexity = O(n)

Extra Space Complexity = O(1)


3. BINARY SEARCH

Binary Search works on sorted data and divides the search
range into smaller parts.

Best Case Time Complexity = O(1)

Worst Case Time Complexity = O(log n)

Average Case Time Complexity = O(log n)

Extra Space Complexity = O(1)


4. TREE HEIGHT ANALYSIS

The longest path is:

CEO -> IT -> Development -> Frontend

Therefore:

Height = 3 edges
Levels = 4


5. OVERALL ANALYSIS

The organisational hierarchy is represented using a tree.
Level-order traversal displays the hierarchy level by level.

Linear Search is simple and does not require sorted data.

Binary Search requires sorted data but reduces the number
of comparisons for larger datasets.
