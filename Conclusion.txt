CONCLUSION
==========

The company organisational hierarchy was successfully
represented using a general tree structure.

The hierarchy contains 8 tree nodes including the CEO
and 7 departments.

Level-order traversal was used to display the hierarchy
level by level.

The traversal order is:

CEO HR Finance IT Development Testing Frontend Backend

Linear Search and Binary Search were implemented to
locate department names.

For the three searches performed, the comparison counts
were:

Development: Linear = 2, Binary = 2
HR: Linear = 5, Binary = 3
Testing: Linear = 7, Binary = 3

Binary Search requires the department names to be sorted,
while Linear Search does not require sorted data.

The tree representation is suitable for organisational
reporting because it clearly shows the relationships
between departments and sub-departments.

A sorted array with Binary Search is suitable for
department searching, particularly when the department
list is maintained in sorted order.
