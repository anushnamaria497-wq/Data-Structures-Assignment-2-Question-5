CONCLUSION

A general (n-ary) tree is a suitable representation of the organisational
hierarchy. Level-order traversal lists departments by reporting level
(CEO -> HR, Finance, IT -> Development, Testing -> Frontend, Backend) in O(n) time.

For locating a department, Binary Search used fewer comparisons than Linear Search
in most cases (Frontend 3 vs 7, Testing 4 vs 6, Marketing 4 vs 8). For HR both
needed 2, because HR is near the front of the original list. As the number of
departments grows, Binary Search's O(log n) advantage increases over Linear
Search's O(n). Binary Search needs sorted data (one-time O(n log n) cost).

Therefore, for organisational reporting and department searching, the tree suits
the hierarchy and a sorted array with Binary Search is the more suitable search
method when the department list changes rarely.
